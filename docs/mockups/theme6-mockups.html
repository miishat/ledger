Theme 6 — three warm-light directions

Each panel is the same dashboard slice rendered with a full token set. All three use fonts already loaded in index.css, so none of them adds a webfont request. Depth here comes from four stacked things: a tinted (never grey) shadow, a gradient card fill, a 1px white inner top highlight, and a decoration layer behind everything.

Clay + espresso ink · Playfair Display / Lato · arch colonnade + paper grain
Option B

Sandstone Deco

Option C

Honeyed Linen

Honey + olive · Playfair Display / Plus Jakarta Sans · linen weave + engraved laurel
